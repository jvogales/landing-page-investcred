# MAX ASSESSORIA - Website

Uma plataforma web moderna para encontrar soluções jurídicas especializadas em defesa de direitos financeiros e benefícios governamentais.

## 📋 Sobre a MAX ASSESSORIA

A **MAX ASSESSORIA** é uma consultoria jurídica especializada em:
- Análise de contratos RMC (Reserva de Margem Consignável)
- Intermediação jurídica com advogados especializados
- Atendimento personalizado para defesa de direitos financeiros
- Proteção contra irregularidades em contratos bancários

## 🚀 Features

- **Design Responsivo** - Interface moderna e adaptável para todos os dispositivos
- **HTML5** - Estrutura semântica e acessível
- **CSS3** - Estilos avançados com animações e efeitos
- **JavaScript** - Interatividade e funcionalidades dinâmicas
- **SEO Otimizado** - Meta tags e estrutura preparada para mecanismos de busca

## 🛠️ Desenvolvimento

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Editor de código (VS Code recomendado)

### Como Começar

1. Clone ou baixe o projeto
2. Abra `index.html` ou `pages/landing.html` no navegador
3. Para desenvolvimento local, use um servidor web (ex: Live Server)

### Estrutura CSS

O arquivo `styles.css` está organizado em seções:
1. Design tokens (:root)
2. Reset + Base
3. Helpers/Utilities
4. Components
5. Dividers/Waves
6. Accessibility
7. Animations
8. Media Queries

## 📱 Responsividade
